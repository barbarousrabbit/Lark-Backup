Lark Backup — User Guide
========================

REQUIREMENTS
  - Windows 10 (build 19041+) or Windows 11
  - D: drive must be present (backups saved to D:\Case Management Platform Backup\)
  - Internet access to reach Lark / Feishu API

QUICK START
  Double-click LarkBackup.exe to run the backup service immediately.
  The program runs silently with no visible window. To stop it, use Task Manager
  or run LarkBackup.exe --uninstall.

INSTALL AS AUTOSTART SERVICE (recommended)
  Double-click install.bat
  This registers the program to start automatically at Windows login,
  then launches it immediately. No further action needed.

UNINSTALL
  Double-click uninstall.bat
  Removes the autostart entry and stops the running service.

WHAT IT DOES
  - Runs a backup daily at 09:00
  - Also performs one backup immediately on startup
  - Downloads the Bitable sheet from Lark and saves it as Excel
  - Backup files:  D:\Case Management Platform Backup\
  - Daily reports: D:\Case Management Platform Backup\Daily_Reports\
  - Logs:          <exe folder>\logs\LarkBackupLog.log  (always next to the exe)

RETRY BEHAVIOR
  On failure, the program retries up to 5 times per day (once per 60 seconds).
  If all attempts fail, it will try again the next day at 09:00.

NOTIFICATIONS
  Windows toast notifications appear on backup success, failure, or data-loss alerts.
  Requires Windows notification permission for "LarkBackup".

SINGLE INSTANCE
  Only one copy can run at a time. A second launch is silently rejected.

TROUBLESHOOTING
  Check the log file for details on any failure.
  Common causes: network unavailable, D: drive missing, Lark API token expired.
